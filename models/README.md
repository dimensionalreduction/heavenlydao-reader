# Models

`ch_PP-OCRv4_det_infer.onnx`: PaddleOCR's PP-OCRv4 mobile text detector (DB), as ONNX. Licensed under the Apache License 2.0 by the PaddlePaddle Authors
(https://github.com/PaddlePaddle/PaddleOCR). Used unchanged by `comics.js` to find where the text of a comic's pictures is (docs/COMICS.md), run in the
browser with onnxruntime-web (`vendor/ort/`).
